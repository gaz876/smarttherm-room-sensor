# Experimental ESP-IDF measurement stage — 2026-11-25

Base: 77ed5aa34e8b0321a6e48c98b8ef1aa1cb06b4e8. The previous codec and its original tests are unchanged. This stage is measurement-only; no network, broker, heating actuation, firmware release or OTA.

Proposed SDK: ESP-IDF v5.5.6. Target ESP32-C3, 4 MB flash. GPIO4 SDA / GPIO5 SCL, external pull-ups, 3.3 V module supply, 100 kHz, address 0x44 are provisional until the exact board/module is checked. No heater. Send soft reset 0x94, wait at least 2 ms; send high precision 0xFD, wait at least 10 ms, then read six bytes. Separate transfers, finite 50 ms I2C timeouts, no numeric output when invalid. Sensirion SHT4x datasheet rev 6.6 table 5 and 8; Espressif ESP32-C3 IDF v5.5.6 I2C API documentation.

Default interval 10 s; proposed 1–3600 s configuration range. Kconfig sets the build-time interval; room_configure supports a runtime caller but persistent settings/UI are not implemented. Temperature correction only. Boot clears all RAM state. Failed reset/write/read, CRC, late/early timing and clock rollback invalidate the sample; next attempt retries sensor reset. A sample is unavailable at age >= interval, measured conservatively from attempt start. Single-owner model; synchronize snapshot and recheck age at actual future publication, do not queue stale values or persist readings. Transport freshness across restarts remains a separate integration gate.
